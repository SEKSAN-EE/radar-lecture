PART 1

What Is Radar?

Definition, what it measures, radar bands, and a short history

What Does “RADAR” Mean?

RAdio Detection And Ranging

1

Transmit a radio wave toward the scene

2

The wave reflects off objects and comes back as an echo

3

Measure the echo: delay → distance, frequency shift → speed, antenna array → direction

 

1 µs echo delay  =  150 m range

R = c·Δt / 2   (the wave travels out and back)

A bat’s echolocation uses the same idea, with sound instead of radio waves (labels: reflected / emitted signal)

Image credits: A proietti (CC BY-SA 3.0)

What Can a Radar Measure?

Range

How far?   R = c·Δt / 2

Velocity

How fast, toward or away?   from Doppler shift

Angle

Which direction?   from phase differences between antennas

Reflectivity

How big, what material?   from echo strength (RCS)

Range–Doppler map: 5 objects at different ranges and speeds

 

Different radar types simply measure these four quantities in different ways.

Radar Frequency Bands

 

Lower frequency: longer range, penetrates ground

 

Higher frequency: small antenna, fine resolution

How it works

The dish spins. Whenever the narrow beam points at an object, an echo returns and a blip is drawn on the PPI display.

Trade-off

A narrow beam separates objects better, but each object is hit only once per rotation, so the picture refreshes slowly.

• Phase φ per element tilts the beam: θ = arcsin(λφ / 2πd)

• No moving parts; beam jumps in microseconds

• AESA: a transmit/receive module behind every element

FMCW: The Chirp

A chirp

A sinusoid whose frequency ramps up linearly with time

Three parameters

Start frequency fc, bandwidth B, duration Tc

Slope

S = B / Tc

Typical 77 GHz car radar

77 → 81 GHz in 40 µs, S = 100 MHz/µs

Example values from Texas Instruments, “Introduction to mmWave Sensing: FMCW Radars” (S. Rao)

Mixing TX and RX: the IF Signal

Delayed copy

The echo is the TX chirp delayed by τ = 2d / c

Mixer

Outputs the difference of TX and RX frequencies

Result

One object = one constant tone

fIF = S · 2d / c

Higher IF frequency

Why Doppler fails

A slow UAV moves almost tangentially: near-zero radial speed, so Doppler cannot separate it from buildings.

Ghost targets

Radar → wall → UAV → radar looks like a target behind the wall. Points inside the environmental boundary are removed; what remains is the UAV track.
